# 0.2.1 스냅샷 개발선 시작

## 배경

`0.2.0`을 배포한 뒤에도 `develop`은 릴리스된 안정 버전을 가리키고 있었다. 다음
작업에서 스냅샷을 검증하고 향후 패치를 개발하려면 새 개발선이 필요하다.

## 결정

`baseVersion=0.2.1`로 설정하고 git에는 `snapshotVersion=`을 빈 값으로 유지한다.
`publish-snapshot.yml` 처리 흐름이 배포 시점에 `-PsnapshotVersion=-SNAPSHOT`을
주입하므로, 저장소에 반영된 프로젝트 메타데이터에는 의미가 분명한 기본 버전만
남는다.

## 결과

저장소는 릴리스 태그를 변경하지 않고 CI/Nightly 검증 후 `develop`에서
`0.2.1-SNAPSHOT`을 배포할 수 있다.

## 검증

- 개발선 시작을 위한 PR 검증은 PR #99에서 통과했다.
- 스냅샷 배포 처리 흐름 실행:
  https://github.com/bluetape4k/bluetape4k-javers/actions/runs/26780485554
  - 이벤트: `workflow_run`
  - 브랜치: `develop`
  - 헤드: `b2e304bb7d96960d30859662a8715851311ee990`
  - 작업: `Publish SNAPSHOT to Maven Central`
  - 결과: `success`
- 대표 아티팩트의 Central 스냅샷 메타데이터 검사가 통과했다.
  - `bluetape4k-javers-bom:0.2.1-SNAPSHOT`
    - 메타데이터 버전: `0.2.1-SNAPSHOT`
    - 스냅샷 값: `0.2.1-20260601.203728-6`
    - 최종 갱신: `20260602000213`
  - `javers-core:0.2.1-SNAPSHOT`
    - 메타데이터 버전: `0.2.1-SNAPSHOT`
    - 스냅샷 값: `0.2.1-20260601.203728-6`
    - 최종 갱신: `20260602000217`
  - `javers-exposed:0.2.1-SNAPSHOT`
    - 메타데이터 버전: `0.2.1-SNAPSHOT`

    - 최종 갱신: `20260602000222`

간단한 메타데이터 검사:

```bash
for artifact in bluetape4k-javers-bom javers-core javers-exposed; do
  curl -fsSL \
    "https://central.sonatype.com/repository/maven-snapshots/io/github/bluetape4k/javers/${artifact}/0.2.1-SNAPSHOT/maven-metadata.xml" |
    grep -E "<version>0.2.1-SNAPSHOT</version>|<value>0.2.1-"
done
```

안정 버전 `0.2.1` GitHub Release는 존재하지 않는다. 또한 이 검증에서는 안정
버전 릴리스 태그나 Maven Central 안정 버전 아티팩트를 생성하지 않았다.
