# 카탈로그 참조 2026-05-25-01

## 배경

공유 `bluetape4k-dependencies` 카탈로그에서 ASM, AWS Kotlin SDK, Apache Fory
의존성을 업데이트했다.

## 결정

기본 `bluetape4kDependenciesCatalogRef`가 `develop`을 계속 따라가지 않도록
`catalog/2026-05-25-01`에 고정한다.

## 결과

이제 Gradle 설정은 릴리스 트레인 카탈로그를 기본으로 가져오며,
`bluetape4kDependenciesCatalogRef` 또는
`BLUETAPE4K_DEPENDENCIES_CATALOG_REF`로 참조를 재정의할 수도 있다.

스냅샷 게시 워크플로도 `develop`을 강제로 체크아웃하지 않고 디스패치된 참조를
체크아웃한다. 따라서 브랜치 게이트를 거친 스냅샷 트레인 검증에서는 Nightly를
통과한 것과 같은 카탈로그 고정 소스를 게시한다.

## 검증

- 설정 파일을 `catalog/2026-05-25-01`로 업데이트했다.
- `./gradlew compileTestKotlin --refresh-dependencies --console=plain -PsnapshotVersion=-SNAPSHOT`
- `actionlint .github/workflows/publish-snapshot.yml`

## 향후 준수 사항

여러 저장소의 의존성 트레인을 함께 업데이트할 때는 날짜가 포함된 카탈로그 태그를
사용한다. 수동으로 디스패치한 스냅샷 게시 워크플로에서 `develop` 체크아웃을
강제하지 않는다. 검증과 게시가 같은 소스 트리를 사용하도록 디스패치 참조를
사용한다.
