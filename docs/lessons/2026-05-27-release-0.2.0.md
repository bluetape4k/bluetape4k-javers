# 0.2.0 릴리스

## 배경

0.2.0 마일스톤에서는 Exposed 저장소, DDD 도우미, CQRS/Event Sourcing 예제 작업을
마무리했다. 릴리스 처리 흐름에서는 `gradle.properties`의 `baseVersion`이 릴리스
태그와 일치해야 한다.

## 결정

`baseVersion=0.2.0`으로 설정하고 `snapshotVersion`을 빈 값으로 유지하며, 태그
생성 전에 0.2.0 변경 이력 섹션을 추가해 안정 버전 릴리스를 준비한다. 이후 사전
검사에서 불일치가 발견되지 않으면 기존 `release.yml` 처리 흐름에
`version=0.2.0`과 기본 카탈로그 참조를 사용한다.

## 검증 계획

- `git diff --check`
- `./gradlew help --no-configuration-cache --no-build-cache --console=plain`
- `./gradlew :javers-core:test :javers-ddd:test :javers-exposed:test --no-configuration-cache --no-build-cache --no-parallel --console=plain`
- 릴리스 준비 PR의 GitHub CI
- `0.2.0`용 릴리스 처리 흐름 `Publish Release`

## 향후 지침

안정 버전 릴리스 처리 흐름을 실행하기 전에 태그가 존재하고, 태그의
`gradle.properties`가 버전과 일치하며, 마일스톤에 열린 이슈가 없고, 동일한
상태에서 수행한 Nightly/Snapshot 검증이 있는지 확인한다.
