# Release 0.2.0

## Context

The 0.2.0 milestone closed the Exposed repository, DDD helper, and CQRS/Event
Sourcing example lane. The release workflow requires `gradle.properties`
`baseVersion` to match the release tag.

## Decision

Prepare the stable release by setting `baseVersion=0.2.0`, keeping
`snapshotVersion` empty, and adding a 0.2.0 changelog section before tagging.
Use the existing `release.yml` workflow with `version=0.2.0` and the default
catalog ref unless a later preflight shows a mismatch.

## Verification Plan

- `git diff --check`
- `./gradlew help --no-configuration-cache --no-build-cache --console=plain`
- `./gradlew :javers-core:test :javers-ddd:test :javers-exposed:test --no-configuration-cache --no-build-cache --no-parallel --console=plain`
- GitHub CI on the release prep PR
- Release workflow `Publish Release` for `0.2.0`

## Future Guidance

Before dispatching a stable release workflow, verify the tag exists, the tag's
`gradle.properties` matches the version, the milestone has no open issues, and a
same-state Nightly/Snapshot validation exists.
