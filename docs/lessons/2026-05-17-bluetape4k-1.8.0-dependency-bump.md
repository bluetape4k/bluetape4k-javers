# Lesson: bluetape4k 의존성 1.8.0-SNAPSHOT → 1.8.0 릴리즈 범프

**날짜**: 2026-05-17
**관련 이슈**: [#29](https://github.com/bluetape4k/bluetape4k-javers/issues/29)
**PR**: chore/bump-bluetape4k-1.8.0

## 변경 내용

`gradle/libs.versions.toml`의 `bluetape4k` 버전을 `1.8.0-SNAPSHOT`에서 `1.8.0`으로 변경.

## 검증

- Maven Central에 `io.github.bluetape4k:bluetape4k-bom:1.8.0` 릴리즈 확인.
- `./gradlew build -x test` → BUILD SUCCESSFUL (7s)

## 결정 근거

0.1.0 릴리즈 전 모든 SNAPSHOT 의존성을 릴리즈 버전으로 전환해야 함.
bluetape4k 1.8.0이 Maven Central에 배포된 것을 확인 후 진행.

## 향후 지침

- 릴리즈 전 `libs.versions.toml`에서 `-SNAPSHOT` 접미사가 붙은 버전을 모두 점검.
- Maven Central 버전 확인: `https://repo1.maven.org/maven2/{group}/{artifact}/maven-metadata.xml`
