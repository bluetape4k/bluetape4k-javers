# 교훈: bluetape4k 의존성을 1.8.0-SNAPSHOT에서 1.8.0 릴리스로 갱신

**날짜**: 2026-05-17
**관련 이슈**: [#29](https://github.com/bluetape4k/bluetape4k-javers/issues/29)
**PR**: chore/bump-bluetape4k-1.8.0

## 변경 내용

`gradle/libs.versions.toml`의 `bluetape4k` 버전을 `1.8.0-SNAPSHOT`에서
`1.8.0`으로 변경했다.

## 검증

- Maven Central에 `io.github.bluetape4k:bluetape4k-bom:1.8.0` 릴리스가
  게시되었는지 확인했다.
- `./gradlew build -x test` → BUILD SUCCESSFUL (7s)

## 결정 근거

0.1.0 릴리스 전에 모든 SNAPSHOT 의존성을 릴리스 버전으로 전환해야 했다.
bluetape4k 1.8.0이 Maven Central에 배포된 것을 확인한 뒤 변경했다.

## 향후 지침

- 릴리스 전에 `libs.versions.toml`에서 `-SNAPSHOT` 접미사가 붙은 버전을 모두 점검한다.
- Maven Central 버전 확인: `https://repo1.maven.org/maven2/{group}/{artifact}/maven-metadata.xml`
