# Javers 0.2 Manual 구현 계획

> **Agentic worker용:** REQUIRED SUB-SKILL: 이 계획은 superpowers:subagent-driven-development(권장) 또는 superpowers:executing-plans로 task-by-task 구현한다. 단계 추적에는 checkbox(`- [ ]`) syntax를 사용한다.

**목표:** 다섯 released library, BOM 하나, DDD/CQRS example 하나, benchmark evidence group 하나, audited dark diagram 다섯 개를 다루는 repository-owned bilingual release-validated Javers 0.2 manual을 publish한다.

**Architecture:** `docs/manual/`은 authoring source of truth다. manifest와 Ruby contract는 release `0.2.1`을 commit `bffe19439ca891fa5301a76421bdef7ba75252a0`에 pin하고, 일곱 release project를 classify하며, English/Korean route parity를 enforce하고 deterministic SVG/PNG asset을 expose한다. website는 나중에 merged source를 versioned `0.2` snapshot으로 import하면서 release 및 authoring provenance를 보존한다.

**Tech Stack:** Markdown/YAML/JSON, Ruby 3 standard library and Minitest, Gradle project inventory export, SVG, CairoSVG, Python diagram audits, Astro/Starlight website sync.

---

## 파일 ownership map

- Publication contract owner: `docs/manual/manifest.yaml`, `docs/manual/generated/manifest.json`, `scripts/manual/*.rb`, root Gradle inventory task.
- Guide owner: `docs/manual/{en,ko}/{index.md,getting-started.md,architecture/**,persistence/**,guides/**,operations/**}`.
- Module owner: five libraries와 BOM용 `docs/manual/{en,ko}/modules/*.md`.
- Learning owner: `docs/manual/{en,ko}/examples/javers-exposed-ddd.md` 및 `docs/manual/{en,ko}/benchmarks/exposed-ddd-envers.md`.
- Diagram/integration owner: `docs/manual/assets/**`, diagram validation, final manifest/index integration, publication metadata.

Worker는 다른 owner의 path를 edit하면 안 된다. 모든 content lane이 끝난 뒤 integration owner가 navigation, manifest, shared-index 변경을 해결한다.
