# examples-javers-spring-boot4

This Spring Boot 4 REST example keeps JaVers and Exposed wiring explicit. Its
command lifecycle preserves the existing duplicate-payment invariant and uses
bluetape4k assertions in the regression test that documents that contract.

- Gradle project: `:examples-javers-spring-boot4`
- Source directory: `examples/javers-spring-boot4`
- Publication: none
