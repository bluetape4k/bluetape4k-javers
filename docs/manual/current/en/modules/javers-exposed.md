# javers-exposed

`javers-exposed` persists JaVers CDO snapshots and commit metadata through
Exposed JDBC. It does not replace application repositories, cache modes, or
framework-specific Exposed runtime helpers.

- Gradle project: `:javers-exposed`
- Artifact: `io.github.bluetape4k.javers:javers-exposed`
- Source directory: `javers-exposed`
