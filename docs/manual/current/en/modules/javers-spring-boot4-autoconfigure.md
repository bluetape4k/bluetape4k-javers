# javers-spring-boot4-autoconfigure

This library supplies conditional Spring Boot 4 configuration for Exposed,
Redis, and Kafka JaVers repositories. Schema ownership and contradictory
configuration flags fail fast; infrastructure beans remain application-owned.

- Gradle project: `:javers-spring-boot4-autoconfigure`
- Artifact: `io.github.bluetape4k.javers:javers-spring-boot4-autoconfigure`
- Source directory: `javers-spring-boot4-autoconfigure`
