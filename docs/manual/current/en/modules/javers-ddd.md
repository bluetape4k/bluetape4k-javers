# javers-ddd

`javers-ddd` adapts aggregate save flows and domain events into JaVers audit
commits. It is a JaVers workflow helper, not a generic DDD contract owner for
the wider bluetape4k ecosystem.

- Gradle project: `:javers-ddd`
- Artifact: `io.github.bluetape4k.javers:javers-ddd`
- Source directory: `javers-ddd`
