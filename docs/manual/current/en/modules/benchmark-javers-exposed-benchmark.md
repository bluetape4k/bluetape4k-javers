# benchmark-javers-exposed-benchmark

`benchmark-javers-exposed-benchmark` is the non-published JMH and Testcontainers
harness for JaVers Exposed commit-metadata index evidence. It records benchmark
reports and teardown failures as separate, fail-closed receipts so an incomplete
run cannot be presented as a clean performance result.

- Gradle project: `:benchmark-javers-exposed-benchmark`
- Source directory: `benchmark/javers-exposed-benchmark`
- Publication: none
