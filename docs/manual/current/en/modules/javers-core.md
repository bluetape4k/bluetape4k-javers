# javers-core

`javers-core` contains the Kotlin JaVers extensions, codecs, cache-backed
repositories, and composite repository boundaries shared by the adapters. The
current line also makes cancellation handling and instance lifetime explicit.

- Gradle project: `:javers-core`
- Artifact: `io.github.bluetape4k.javers:javers-core`
- Source directory: `javers-core`
