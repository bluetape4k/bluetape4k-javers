# javers-exposed

`javers-exposed`는 Exposed JDBC를 통해 JaVers CDO snapshot과 commit metadata를
저장합니다. 애플리케이션 repository, cache mode, framework 전용 Exposed
runtime helper를 대신하지 않습니다.

- Gradle project: `:javers-exposed`
- Artifact: `io.github.bluetape4k.javers:javers-exposed`
- Source directory: `javers-exposed`
