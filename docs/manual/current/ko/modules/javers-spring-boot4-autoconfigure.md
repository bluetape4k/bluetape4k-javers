# javers-spring-boot4-autoconfigure

이 library는 Exposed, Redis, Kafka JaVers repository를 위한 조건부 Spring Boot
4 자동 구성을 제공합니다. schema ownership과 모순된 configuration flag는
fail-fast로 처리하며 infrastructure bean은 애플리케이션이 소유합니다.

- Gradle project: `:javers-spring-boot4-autoconfigure`
- Artifact: `io.github.bluetape4k.javers:javers-spring-boot4-autoconfigure`
- Source directory: `javers-spring-boot4-autoconfigure`
