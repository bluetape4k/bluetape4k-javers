# javers-core

`javers-core`는 adapter가 공유하는 Kotlin JaVers extension, codec, cache-backed
repository, composite repository 경계를 제공합니다. 현재 라인은 cancellation
처리와 객체 수명도 명시적인 계약으로 다룹니다.

- Gradle project: `:javers-core`
- Artifact: `io.github.bluetape4k.javers:javers-core`
- Source directory: `javers-core`
